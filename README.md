# LunaticMuch Tap

## How do I install these formulae?

`brew install lunaticmuch/tap/<formula>`

Or `brew tap lunaticmuch/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "lunaticmuch/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
